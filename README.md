# ⌨️ Typing Speed Test

A simple and interactive Typing Speed Test application built with Python and Tkinter. It helps users measure their typing speed, accuracy, and performance through randomly selected sentences and real-time visual feedback.

## ✨ Features

- **Typing Speed Measurement:** Calculates typing speed in Words Per Minute (WPM).
- **Accuracy Calculation:** Measures the percentage of correctly typed characters.
- **Real-Time Feedback:** Displays correct characters in green and incorrect characters in red.
- **Live Timer:** Starts automatically when you begin typing.
- **Performance Rating:** Classifies typing speed into Beginner, Average, Good, Fast, and Expert.
- **Best Score Tracking:** Keeps track of your highest WPM score during the current session.
- **Random Sentences:** Provides different sentences for each test.
- **Error Validation:** Requires at least 60% accuracy to qualify for a performance rating.
- **User-Friendly Interface:** Features a clean, dark-themed graphical interface.
- **New Test Option:** Allows users to start another typing test easily.

## 🛠️ Technologies Used

- **Python** — Core programming language.
- **Tkinter** — Graphical user interface.
- **Random** — Random sentence selection.
- **Time** — Timer and typing duration calculations.

## 📋 Requirements

- Python 3.8 or later recommended.
- Tkinter (usually included with standard Python installations).

No external Python packages are required.
